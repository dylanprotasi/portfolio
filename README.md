# Portfolio Dylan Protasi

Statische website (geen build nodig).

- `index.html` – de hele site
- `video/` – alle video's (1080p mp4)
- `img/` – alle foto's (jpg)

Online zetten via GitHub Pages: Settings → Pages → Branch `main`, map `/ (root)`.
Test lokaal: start in deze map `python3 -m http.server` en open http://localhost:8000
